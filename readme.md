# React Weather Project
## Project Description
Update packages and improve UI UX for the React Weather application.
## Tech Stack and Dependencies
The project uses the following tech stack and dependencies:
* React
* Node.js
* Webpack
## Getting Started
To get started with the project, follow these steps:
1. Clone the repository: `git clone https://github.com/devstojko/ReactWeather.git`
2. Install dependencies: `npm install`
3. Start the application: `npm start`
## Project Structure
The project has the following structure:
* `app`: Application code
* `public`: Public assets
* `server.js`: Server-side code
* `webpack.config.js`: Webpack configuration
* `package.json`: Project dependencies and scripts
## Features
The project includes the following features:
* Updated packages for improved performance and security
* Improved UI/UX for better user experience
